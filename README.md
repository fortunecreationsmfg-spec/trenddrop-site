# TrendDrop

Marketing site for **TrendDrop**: the top 3 most viral TikToks in your niche, emailed every morning. Operated by **FortuneCreations, LLC**.

The content comes from the original Wix site (https://fortunecreationsut.wixsite.com/trenddrop). Sign-up and checkout go through a Stripe payment link ($19/month).

Stack: Next.js App Router, TypeScript, Tailwind CSS 4, Vercel Analytics. It's the same setup as `aicityphone-site`.

```bash
npm install && npm run dev
```

Deploy: Vercel → Import Git Repository → this repo (Next.js preset, `main`). No env vars are needed.
